# Portfolio

A modern, interactive developer portfolio built with **React** — featuring animated page transitions, a radial skills visualizer, project showcase with modal previews, and a dark/light aesthetic powered by styled-components.

## ✨ Features

- **Animated Landing Page** — YinYang-driven dark mode toggle with smooth transitions
- **Radial Skills Visualizer** — Canvas-based animated diagram showcasing tech stack
- **Projects Showcase** — Interactive list with cursor-following previews and detail modals
- **Certifications Page** — Highlight of achievements and credentials
- **Resume Page** — Downloadable resume with clean layout
- **Particle Backgrounds** — Ambient particle effects across pages
- **Fully Responsive** — Optimized for desktop, tablet, and mobile

## 📁 Project Structure
```
src/
├── components/          # Page components (Main, Projects, Skills, etc.)
├── subComponents/       # Reusable UI pieces (Logo, SocialIcons, PowerButton...)
├── data/                # Project and blog data
├── config/              # Particles.js config files
├── globalStyles.js      # Global styled-components theme
└── App.js               # Routes and theme provider
```

## 🚀 Getting Started

### Prerequisites
- Node.js ≥ 16
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Ranjitha04-S/ranjitha-portfolio.git

# Navigate into the project
cd ranjitha-portfolio

# Install dependencies
npm install

# Start the development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
